# Node.js Basics Assignment

## Assignment Description

This assignment is my first practice with Node.js. The goal was to create simple Node.js programs, run them through the terminal, and display information using `console.log()`.

I created two programs:

- `app.js` - Displays basic Node.js messages.
- `introduction.js` - Displays my personal introduction.

## Steps to Run

1. Make sure Node.js is installed.
2. Open the project folder in the terminal.
3. Run the first program:

```bash
node app.js
then
node introduction.js
```

Commands Used
node app.js
node introduction.js
